# Real-phone test checklist

Open https://dirtyurch-pixel.github.io/StudioBars/ on your phone. Tick each item, and note anything odd: a
screenshot plus one line ("what I did, what happened") is perfect.

## A. Writing (about 5 min)
1. Tap **New song**, give it a title, and write 4 lines. Make one line long enough to wrap.
   - [ ] Long lines wrap onto the next ruled line. Nothing scrolls sideways.
   - [ ] The keyboard's Enter key makes a new line.
2. Lock one line, then try to type on it.
   - [ ] It won't change.
3. Close the browser tab completely and reopen the link.
   - [ ] Everything is still there, including the lock.

## B. Offline (about 3 min)
4. Go to **Settings → Working offline**.
   - [ ] It shows ✓ for the app and the rhymes dictionary.
   - [ ] Tap "Download word meanings for offline".
5. Turn on **airplane mode**, then close and reopen the app.
   - [ ] It opens and shows your song.
   - [ ] Syllable counts and rhyme colours work.
   - [ ] Look up a word in **Words**: the meaning shows.
   - [ ] Type a new line, then turn airplane mode off. The line is still there.

## C. Backup (about 5 min)
6. On the home screen, tap **Back up**.
   - [ ] It says "Backup checked ✓", and a file downloads.
7. Save that file to **Google Drive**, using the share button in Settings or your Downloads app.
8. Go to **Settings → Restore a backup…** and pick the file from Drive.
   - [ ] It says "Backup checked ✓ made…".
   - [ ] Tap **Add what's missing**: nothing is duplicated.

## D. Music and recording (about 5 min)
9. **♪ Library** → **Choose music from this device** → pick a beat.
   - [ ] It plays.
   - [ ] The waveform shows.
   - [ ] **Tap** along to set the BPM.
10. In a song: **Craft → Record**, then record 10 seconds.
    - [ ] It plays back.
    - [ ] Is the timing against the beat roughly right?

## E. Install (optional)
11. Use the browser menu → **Add to Home screen**, then open it from the icon.
    - [ ] It opens full-screen, and your songs are there.

- Anything confusing, slow or ugly:
- Did any step fail? Which one, and what did the screen say?
