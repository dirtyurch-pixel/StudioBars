# AI rulebook (applies to AI coding assistants and the in-app AI)

1. Build only the phase the owner has explicitly authorised; then stop.
2. Never claim something works unless it was actually run; report failures honestly.
3. Never commit secrets, `.env`, lyrics, databases or audio. No force-push; no merging to `main` without owner approval.
4. In-app AI suggests only. It never writes into the editor and never changes a locked line.
5. Never send lyrics to a provider without showing the user what is sent. Never log keys or lyric text.
6. No copying of copyrighted lyrics. Label estimates as estimates.
