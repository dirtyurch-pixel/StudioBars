# Product decisions — approved scope

- **Working name:** Studio Bars (placeholder; branding availability not yet confirmed).
- **Language:** English only.
- **Genres:** Hip-Hop, R&B, House and Pop; hybrid genre combinations supported.
- **Platforms:** Windows-first, with a usable Android/mobile browser interface and later packaging options. Device-specific audio storage is not automatically synchronised.
- **Visual design:** Royal Blue & Amber; midnight navy main background; warm yellow ruled writing pad; responsive editor; matching mobile and PC style. Alternate themes can be added in Settings.
- **Purpose:** A lyric-writing studio with local editing and optional AI assistance, not a full DAW.
- **Author's control:** AI proposes only. Locked lyric lines are inviolate until explicitly unlocked. Preserve version history.
- **Words/data:** CMUdict phonemes, WordNet meaning relationships, optionally Datamuse; custom phrase/rhyme lexicon and local song library. Respect licences and API availability.
- **Music player:** User-imported local tracks, playlists, A–B loops, adjustable speed, linked writing sessions and playback while editing.
- **Approved additions:** All 15 previous enhancements; all 12 competitor-inspired additions; Writing Session Mode; later melody/sketch features.
- **Development:** Stage-by-stage, no coding until explicit phase permission, verified GitHub push after each authorised/tested stage; private repo preference; no stage jumping.
- **Deferred/unknown until stage:** Final app name, choice of AI provider, exact editor component, cloud sync, audio analysis algorithms, mobile packaging, collaboration authentication. No automatic paid hosting/AI commitment.
