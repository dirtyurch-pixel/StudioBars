# Licence and attribution plan

Phase 0 bundles no third-party data. Dependencies are standard open-source packages (React, Vite, Tailwind, FastAPI, etc.) under their own licences (see `package-lock.json` / `requirements.txt`).

Later phases, to verify at the time of use and record here with full notices:
- CMU Pronouncing Dictionary (Phase 2)
- Princeton WordNet (Phase 3)
- Datamuse API terms (Phase 3, online, optional)
- Word-frequency and part-of-speech sources for rhyme filters (Phase 2/3)
