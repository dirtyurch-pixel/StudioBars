# WordNet 3.0 (Princeton University)

(`WordNet-3.0.tar.gz`, SHA-256 `640db279c949a88f61f851dd54ebbb22d003f8b90b85267042ef85a3781d3a52`,
from https://wordnetcode.princeton.edu/3.0/WordNet-3.0.tar.gz, retrieved 2026-11-01), `dict/` folder only:
`data.*`, `index.*`, `*.exc` and `lexnames`. `MANIFEST.sha256` lists a checksum for every file and a test checks it.
